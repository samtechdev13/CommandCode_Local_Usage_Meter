Reading your limits from Command Code.

Runs entirely on your machine. The only outbound requests go to api.commandcode.ai; there are no analytics, no cookies and no external assets.

What is stored, and where
  • Your API key lives in config.json in this folder, file mode 600. It is never returned by the server to this page.
  • The dashboard holds usage numbers in memory only; nothing is written to your browser.
  • The server is bound to 127.0.0.1, so other machines on the network cannot reach it.
  • Remove the key at any time from the connection panel (“Forget stored key”).
